# SEO Strategy — XXXVII (The 37)

## In scope
- All public-facing routes: `/` (home manifesto), `/atlas`, `/cause/:slug` (37 cause detail pages), `/dimensions`, `/infos`, `/contacts`

## Out of scope
- None — there are no authenticated/admin pages in this project.

## Site description
A dark, cinematic atlas site for "The 37": 37 causes across 10 dimensions of human existence. Manifesto/movement site; users can claim a cause via a contact form.

## Rendering mode
**Pure SPA (React + Vite + Wouter).** There is no SSR layer. All route content is client-rendered. The only HTML returned to crawlers is the static `artifacts/the37/index.html` shell.

## Target audience
People interested in long-termism, civilizational progress, futurism, and cause-driven action.

## Primary keywords
- XXXVII / The 37
- Per-cause topics (e.g., "longevity escape velocity", "morphological freedom", "decentralized sensemaking")
- "Exponential future", "civilizational causes"
